# Antigravity Workspace Rule: Senior-Junior Collaboration

이 파일은 `GEMINI.md`와 연동되어 Antigravity 에이전트의 시니어/주니어 모드 및 관문 규칙을 적용합니다.
최상위 규칙 원문은 저장소 루트의 `GEMINI.md` 및 `개발산출물/협업_시니어주니어.md`를 따릅니다.

## 핵심 가이드라인
1. **역할 자동 판별**: 세션 지시문이 `?0`(명세), `리뷰`, `설계`이면 **시니어(Effort 높음)**, `구현 step`, `리뷰 반영`이면 **주니어(Effort 중간)**로 동작합니다.
2. **구현 명세서 부재 시 중단**: `개발산출물/명세/<step ID>_구현명세.md`가 없으면 코드를 작성하지 않고 즉시 멈춥니다.
3. **묶음 완료 시 중단**: 묶음 마지막 step 완료 시 즉시 멈추고 다음 명세 step(`?0`)을 안내합니다.
4. **체크리스트 동적 피드백**: PR 전 `개발산출물/주니어_체크리스트.md` 전수 대조, 리뷰 반영 시 새 지적 사항을 체크리스트에 누적합니다.
5. **PR 머지는 항상 사용자**: 에이전트는 `gh pr checks --watch`로 CI 통과까지만 대기하며 머지하지 않습니다.
