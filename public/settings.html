구글 계정으로 로그인하면 연습 기록과 녹음을 어디서나 이어갈 수 있어요.

계정

Google 계정으로 로그인하면 노션 설정 없이도 연습 곡과 녹음을 바로 저장할 수 있어요.

새 창에서 로그인 ↗

로그인 계정:

계정 삭제 (모든 연습 기록·녹음·연동 키 영구 삭제)

계정을 삭제하면 서비스에 저장된 모든 곡, 연습 기록, 녹음 오디오 파일, 외부 API 키가 즉시 삭제되며 복구할 수 없어요. (본인 Google Drive에 올린 파일은 드라이브에 그대로 남아요.)

노션 연결 · 플레이어와 녹음

연습 플레이어가 위치·구간·속도, 연습 시간, 녹음을 노션 악기 연습에 저장할 때 거치는 중계 서버(Google Apps Script)예요.

  1. 중계 서버 만들기 안내대로 Apps Script를 웹 앱으로 배포
  2. 나온 웹 앱 URL과 스크립트 속성의 PRACTICE_KEY를 아래에 입력

학습 노트 · Gemini 분석

NOTES에서 분석을 요청하면 이 저장소의 GitHub Actions가 실행돼요. 실행할 수 있는 GitHub 토큰이 필요해요.

  1. Fine-grained 토큰 발급에서 Repository access를 이 저장소만 선택
  2. Repository permissions → Actions: Read and write 하나만

노션 바로가기

첫 화면의 NOTION과 NOTES 페이지에서 여는 링크예요. 노션에서 페이지 링크 복사로 가져오세요. 비워 두면 숨겨져요.
