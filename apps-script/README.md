# 노션 중계 서버 (Google Apps Script)

연습 플레이어(`practice.html`)가 노션에 저장할 때 거치는 작은 서버입니다. 노션 토큰을 공개 페이지(github.io)에 넣지 않으려고 씁니다. 구글 계정만 있으면 무료입니다.

## 만들기

1. https://script.google.com → **새 프로젝트** → 이름을 `practice-notion`으로
2. 기본 `Code.gs` 내용을 전부 지우고 이 폴더의 `Code.gs` 내용을 붙여넣기 → 저장(⌘S / Ctrl+S)
3. 왼쪽 톱니바퀴 **프로젝트 설정** → 맨 아래 **스크립트 속성** → **스크립트 속성 추가**로 두 개 넣고 **저장**
   - `NOTION_TOKEN`: 노션 통합 토큰 (notion.so/my-integrations에서 만든 것, `ntn_…`)
   - `PRACTICE_KEY`: 아무 긴 문자열 (비밀번호처럼. 플레이어에 한 번 넣음)
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 승인 창이 뜨면 본인 계정 선택 → "Google에서 확인하지 않은 앱" 화면에서 **고급 → practice-notion(으)로 이동** → **허용**
   (외부 주소에 요청을 보내는 권한입니다. 내가 만든 스크립트라 확인이 안 된 것일 뿐입니다)
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사

브라우저에서 그 주소를 열어 `{"ok":true,...}`가 보이면 배포된 것입니다.

노션 **악기 연습** 페이지 `···` → **연결**에 그 통합이 추가돼 있어야 합니다.

### 코드를 고친 뒤 다시 배포할 때

**배포 → 배포 관리** → 연필 아이콘 → 버전을 **새 버전**으로 → **배포**. 이렇게 하면 주소가 그대로 유지됩니다. (**새 배포**를 누르면 주소가 바뀝니다)

스크립트 속성만 바꿨을 때는 다시 배포하지 않아도 됩니다.

## 플레이어에 연결

**SETTING**(`settings.html`) → **노션 연결** → 웹 앱 URL과 `PRACTICE_KEY` 입력 → **저장 후 연결 확인**. 플레이어 곡 목록 맨 아래 링크로도 갈 수 있습니다.
기기(아이패드, PC)마다 한 번씩 하면 됩니다.

한 번에 넣는 주소도 있습니다. 아래를 그 기기 브라우저에서 한 번 열면 저장되고 주소창에서는 지워집니다. 노션 임베드 주소로는 쓰지 마세요(노션 블록에 키가 그대로 남습니다).

```
https://hunseokc.github.io/ULevelP/practice.html#api=웹앱URL&k=비밀키
```

## 노션에서 바로 연습 열기

곡 데이터베이스에 수식 속성(예: `연습하기`)을 추가하면 곡마다 플레이어 링크가 생깁니다. 곡을 추가할 때 `유튜브 링크`만 붙여넣으면 됩니다.

```
link("▶ 연습", "https://hunseokc.github.io/ULevelP/practice.html?v=" +
  replace(prop("유튜브 링크"), ".*(v=|youtu[.]be/|shorts/|embed/|live/)([-_0-9A-Za-z]{11}).*", "$2"))
```

플레이어가 열리면 노션에 저장된 위치·구간·속도를 불러옵니다. 마지막 상태까지 담긴 링크는 `이어서 연습` 속성에 자동으로 저장됩니다.

## 녹음

플레이어의 **● 녹음**을 누르고, 멈추면 바로 올라갑니다. 녹음은 그날 **연습 기록** 페이지에 두 군데 붙습니다.

- 본문: `🎙 14:32 · 1:05–1:40 · 0.75× · 0:42` 한 줄과 오디오 블록. 페이지를 열면 바로 재생됩니다
- `녹음` 파일 속성: 표에서 녹음한 날을 보는 용도

연습 기록 데이터베이스에 `녹음` 파일 속성이 있어야 합니다. 노션 무료 플랜은 파일 하나에 5MB까지이고, 연결 확인을 하면 플레이어에 이 워크스페이스의 한도가 표시됩니다. 한 번에 30분까지 녹음할 수 있습니다.

마이크는 브라우저에서 직접 연 플레이어에서만 쓸 수 있습니다. 노션 페이지에 임베드한 플레이어에서는 마이크 권한이 막혀 있습니다.

## 선택 속성

| 이름 | 기본값 | 용도 |
| --- | --- | --- |
| `SONGS_DB` / `SESSIONS_DB` | 지금 쓰는 노션 데이터베이스 ID | 데이터베이스를 새로 만들었을 때 |

## 요청 형식

Apps Script는 커스텀 헤더와 CORS preflight를 받지 못해서, 플레이어는 모든 요청을 `Content-Type: text/plain` POST 하나로 보냅니다. 응답은 항상 200이고 실패하면 `{ error }`가 들어 있습니다.

```json
{ "key": "PRACTICE_KEY", "path": "/save", "method": "POST", "query": {}, "body": { ... } }
```

| path | method | 내용 |
| --- | --- | --- |
| `/health` | GET | 노션 연결과 속성 이름 확인 |
| `/songs` | GET | 연습 곡 목록 (연습 중 → 보류 → 완료, 최근 연습 순) |
| `/song` | GET | `query.v` 영상으로 곡 찾기 |
| `/song` | POST | 곡 추가 `{videoId, title?, artist?}` (제목이 없으면 유튜브에서 가져옴) |
| `/save` | POST | 위치·구간·속도 저장 + 오늘 연습 기록에 시간·반복 횟수 더하기 |
| `/record` | POST | 녹음 올리기 `{songId, videoId, date, time, a, b, rate, seconds, mime, data(base64)}` |
