# ULevelP 코드 진행 기능 기획 메모

Oct 30, 2026 · @더덕

## 확정된 결정

### 1. 명칭과 데이터 범위

- "자주 쓰는 진행 요약" 명칭은 폐기하고 **취향 코드 진행**으로 바꿉니다.
- 데이터 범위는 **레퍼런스 / 분석 / 합산** 토글로 고릅니다. 기본값은 레퍼런스입니다.

### 2. 수집 경로

| 입력 | 코드 분석 DB 반영 | 비고 |
| --- | --- | --- |
| 코드 진행 영상 (진행을 보여주는 전용 영상) | 바로 들어감 | 검수 없이 반영 |
| 학습 영상 노트 (화성 태그 강의 등) | 기본은 안 들어감 | "코드 진행 수집에 넣기" 버튼(토글)을 켰을 때만 반영 |

### 3. AI 추출값 반영 방식

- AI가 뽑은 값은 검수 없이 바로 반영합니다. 가끔 틀린 값이 섞이는 것을 감수하고 편의성을 택했습니다.
- 나중에 고치기 쉽도록 각 행에 `출처: AI / 직접` 표시를 남겨두길 권합니다. 노션에서 바로 수정할 수 있고, 필요하면 AI 값만 걸러 볼 수 있습니다.

### 4. 코드 진행 영상 입력란 안내 문구 (초안)

> 코드 이름과 누른 건반이 화면에 크게 보이는 영상이 가장 잘 인식돼요. 예: 화면에 코드명(FM9, Ab9sus4)이 크게 뜨고, 건반이 색으로 표시되면서 음이름이 붙어 있는 영상. 연주만 들리거나 손만 보이는 영상은 진행이 틀릴 수 있어요.

인식 기준은 **코드 심볼 + 하이라이트된 건반 + 음이름 라벨**이 모두 화면에 보이는 영상입니다. 이런 영상이면 프롬프트의 "화면 표기 우선" 규칙이 그대로 적용되어, 근거가 대부분 `화면`으로 잡힐 것으로 봅니다.

## 구조 방향

앱 기능을 "공부"와 "연습" 두 묶음으로 나누는 방향입니다. UI와 페이지 배치는 아직 정하지 않았습니다.

| 묶음 | 포함 기능 |
| --- | --- |
| 공부 | 학습 영상 노트, 코드 진행 수집(코드 분석 + 레퍼런스), 취향 코드 진행 |
| 연습 | 코드 연습실(chords), 유튜브 구간 연습 플레이어(practice) |

두 묶음은 두 가지로 이어집니다. 수집한 진행의 타임스탬프로 구간 반복 연습을 열 수 있고, 진행에서 연습실 보이싱으로 넘어갈 수 있습니다.
