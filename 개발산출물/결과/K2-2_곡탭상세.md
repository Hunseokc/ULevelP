### 2.4 A/B 비교 듣기 재검증 출력 (PR #19 시니어 리뷰 1·2번 반영)

헤드리스 Chrome(CDP) 환경에서 3개 시나리오 전수 검증:
① 2개 체크 → A 재생 및 상호 배타 정지
② 3번째 체크 → A 재생 시 `abAudioA.dataset.takeId`가 새 take의 id인지 확인
③ 하나 해제 후 다시 체크 → `src` 및 `dataset.takeId` 정리 후 정상 재요청·재생되는지 확인

## 4. 명세와 달라진 점 및 겪은 문제

1. **Exposed Table Column id 접근 방식:**
   - `SessionsTable`과 `TakesTable`은 일반 `Table`에 `val id = uuid("id")`로 선언되어 있어, `ResultRow` 접근 시 `row[SessionsTable.id]`의 반환형이 바로 `java.util.UUID`임.
   - `IdTable`의 `EntityID`에 쓰는 `.value`를 붙이지 않고 `row[SessionsTable.id].toString()`으로 직접 변환함.
2. **Node 22+ vm Sandbox 객체 shallow copy:**
   - `test/data.test.js` D15에서 반환 객체를 `{ ...res }`로 복사 후 비교하여 Node vm sandbox 프로토타입 불일치 방지.
3. **XSS 정적 검사 (c), (d) 규칙 준수:**
   - `log.js`에서 DOM 탐색 시 문자열 selector 대신 `querySelectorAll` 순회 방식을 사용하여 정적 검사 오탐을 방지함.
   - `<a>` 태그 href 및 `<audio>` src 속성에 직접 `safeUrl(...)` 또는 `encodeURIComponent(...)`를 연결하여 보안 가드레일을 통과함.
4. **macOS 헤드리스 크롬 경로 감지:**
   - `csp_check.js`의 `CHROME` 후보 목록에 Playwright 캐시 경로(`~/Library/Caches/ms-playwright/...`)를 추가하여 환경 변수 지정 없이도 로컬 Chrome 테스트가 원활히 동작하도록 함.
5. **PR #19 시니어 리뷰 1~4번 반영:**
   - **리뷰 1번 (audio.src 빈 문자열 초기화 버그):** `audio.src = ''`는 문서 URL을 반환하므로 `audio.removeAttribute('src'); audio.load(); delete audio.dataset.takeId;`로 변경하고 `dataset.takeId !== t.id`로 적재 여부를 판별하도록 수정 (`log.js`).
   - **리뷰 2번 (3번째 체크 시 슬롯 오디오 잔존 버그):** `updateAbPanel`에서 각 슬롯의 `audio.dataset.takeId !== take.id` 여부를 검사하여 슬롯 변경 시 오디오 리셋 및 새 takeId 반영.
   - **리뷰 3번 (home.js API 중복 호출 및 uid 불일치 버그):** `ULAuth.getUser()`로 세션 사용자를 읽고 `onChange` 콜백에서 uid가 변경될 때만 `loadSongs()`를 호출하도록 수정. 단독 `loadSongs()` 및 `'logged_in'` 대체값 제거 (`home.js`).
   - **리뷰 4번 (빠른 연속 요청 레이스 컨디션 버그):** `loadLog`, `loadSongsTab`, `loadSongDetail`에 요청 순번(`logReqSeq`, `songsReqSeq`, `detailReqSeq`)을 도입하여 최신 요청 응답만 화면에 반영하도록 방어 (`log.js`).
