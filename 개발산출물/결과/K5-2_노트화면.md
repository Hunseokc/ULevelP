### 3.2 `ULData.notes` 클라이언트 API 메서드 목록

- `ULData.notes.analyze({ url, tags, targetPart, difficulty })`: `POST /api/v1/notes/analyze`
- `ULData.notes.listJobs({ limit = 20, cursor = null } = {})`: `GET /api/v1/notes/jobs`
- `ULData.notes.getJob(jobId)`: `GET /api/v1/notes/jobs/{jobId}`
- `ULData.notes.list({ tag, targetPart, difficulty, q, limit = 20, cursor = null } = {})`: `GET /api/v1/notes`
- `ULData.notes.get(noteId)`: `GET /api/v1/notes/{noteId}`
- `ULData.notes.update(noteId, { memo, tags, difficulty, title })`: `PATCH /api/v1/notes/{noteId}`
- `ULData.notes.remove(noteId)`: `DELETE /api/v1/notes/{noteId}`
- *특이사항: 412 `NO_KEY` 발생 시 또는 작업 에러 메시지에 `PROVIDER_KEY_INVALID:` 포함 시 `clearCachedGeminiKey()`가 자동 호출되어 `ulp:keys`의 gemini 캐시를 무효화함.*

## 4. 명세와 달라진 점 및 겪은 문제

### 4.1 명세와 달라진 점
- 없음. 명세서의 파일 목록, API 시그니처, DTO 필드, 검증 항목을 1:1로 정확히 준수함.

### 4.2 겪은 문제 및 해결
1. **`NotionPushApiTest` NP16 check constraint 위반:**
   - 문제: `NP16` 테스트 데이터 준비 중 `notes.difficulty`에 `'초급'`을 전달하여 DB check 제약 위반 에러 발생.
   - 원인: `V1__init.sql`의 제약 조건은 `CHECK (difficulty IN ('입문', '중급', '고급'))`임.
   - 해결: `'입문'`으로 수정하여 제약 조건을 준수함.
2. **`test/security.test.js` (d) 규칙 위반 경고:**
   - 문제: `note.js`에서 `practice.html?v=${videoId}&t=${sec}` 동적 리터럴 및 `note.url` 할당 시 정적 토큰 분석기 경고 발생.
   - 해결: `note.url`에 `safeUrl()` 적용, URL 파라미터 조합 시 `encodeURIComponent(sec)` 연결을 적용하여 67개 보안 테스트 전체 통과.
3. **Playwright `E10` `#noteHeader` hidden 타임아웃:**
   - 문제: `note.html` 페이지 로드 직후 `loadDetail()`이 세션 복원 전 즉시 실행되어 401 반환 → `#noteContent`가 hidden으로 유지됨.
   - 해결: `note.js`와 `notes.js`의 진입점을 `start()` 비동기 함수로 래핑하여 `await window.ULAuth.getAccessToken().catch(() => {})`를 선행 완료한 후 데이터를 요청하도록 수정하여 E10 통과.
4. **`csp_check.js` 대조군 실패:**
   - 문제: `node 개발산출물/자료/csp_check.js` 직접 실행 시 로컬 서버(포트 3000)가 기동되어 있지 않아 Chrome이 브라우저 기본 에러 페이지를 띄우면서 CSP 차단이 발생하지 않음.
   - 해결: 백그라운드에서 `node server.js` 기동 후 `csp_check.js`를 재실행하여 13개 화면 검사 0 fail 통과 확인.

## 6. 시니어 2차 리뷰 권장사항 반영 내역 (PR #28)

- **1. uid 추출식 단순화 (`public/note.js`, `public/notes.js`):**
  - `auth.js`의 `onChange`는 항상 `{ user }` 객체를 넘기므로 삼항 fallback을 `const uid = state && state.user ? state.user.id : null;` 형태로 단순화 및 통일.
- **2. 로그아웃/계정전환 시 숨겨진 DOM 입력값 초기화 (`public/note.js`):**
  - `clearNoteDom()` 함수를 신설하여 `uid !== activeUid` 및 비로그인/로그아웃 분기에서 `#noteMemoInput` textarea, 태그, 제목, 요약 등 숨겨진 DOM 요소들의 값을 완전히 비워 이전 사용자 데이터 잔존 원천 차단.
- **3. 회귀 E2E 검증 보강 (`test/e2e/xss.spec.js`):**
  - 기존 1차 회귀 검증의 임의 타이머(`waitForTimeout(300)`)를 `page.waitForResponse`로 교체하여 결정적 대기로 개선.
  - 신규 E2E 테스트 추가: "회귀 검증: note.html 조회 지연 중 A -> B 계정 전환 시 이전 계정(A) 응답 무시 (K5-2 2차 리뷰)" (12 passed).
- **4. 체크리스트 일반화 갱신 (`개발산출물/주니어_체크리스트.md`):**
  - 26번 항목에 DOM 입력값 초기화 및 `PR #28 2차 리뷰 1·2번` 출처 보강.
  - 테스트 섹션에 `waitForResponse` 결정적 대기 규칙(`PR #28 2차 리뷰 3번`) 항목 추가.
