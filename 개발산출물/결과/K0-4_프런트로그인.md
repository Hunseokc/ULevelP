## 2. 외부 설정 체크리스트 (사람)

실제 Google OAuth 로그인 및 원격 DB 연동을 위해 아래 외부 대시보드 설정과 마이그레이션을 확인·적용합니다.

1. **Google Cloud Console (`APIs & Services` → `Credentials`):**
   - OAuth 2.0 클라이언트 ID(웹 애플리케이션) 생성
   - **승인된 JavaScript 원본:** `https://hunseokc.github.io`, `http://localhost:3000`
   - **승인된 리디렉션 URI:** `https://vefrfhafmiiivpgjhqiu.supabase.co/auth/v1/callback`
2. **Supabase 대시보드 (`vefrfhafmiiivpgjhqiu`):**
   - `Authentication` → `Providers` → `Google`: 활성화 후 Google 클라이언트 ID·시크릿 입력
   - `Authentication` → `URL Configuration`:
     - **Site URL:** `https://hunseokc.github.io/ULevelP/`
     - **Redirect URLs:** `https://hunseokc.github.io/ULevelP/**`, `http://localhost:3000/**`, `https://hunseokc.github.io/guitar-practice/**`
   - `Project Settings` → `API`: Publishable key(`sb_publishable_...` 또는 `anon` public key)를 복사해 `public/config.js`의 `supabaseAnonKey`에 입력
3. **원격 DB `V1__init.sql` 마이그레이션 적용:**
   - `.env`에 `REMOTE_DB_HOST`, `REMOTE_DB_PORT`, `REMOTE_DB_NAME`, `REMOTE_DB_USER`, `REMOTE_DB_PASSWORD` 및 `SUPABASE_URL=https://vefrfhafmiiivpgjhqiu.supabase.co` 설정 후 Ktor 서버 기동(`./gradlew run`) 시 Flyway가 자동으로 `V1__init.sql` 12개 테이블을 원격 DB에 적용합니다.
