## 4. 명세와 달라진 점 및 겪은 문제

- **명세와 달라진 점:** 없음. 명세서 1절의 24개 대상 파일과 정확히 1:1로 일치하게 구현하였으며, 33개 디자인 토큰, `.site-nav` 1120px 정렬, 곡률 0px/9999px 전수 교정, Vite 빌드 출력 `dist/` 격리, 공통 래퍼 및 보안 컴포넌트 규격을 100% 준수함.
- **겪은 문제:**
  - `public/site.css` 및 `public/styles.css`에서 Windows 플랫폼 줄바꿈(CRLF)과 Bash/Node 줄바꿈 차이로 인한 정규식 불일치 가능성이 있었으나, Node 기반 scratch 스크립트에서 `\r\n`을 `\n`으로 정규화하여 안전하게 치환함.
  - `test/r0_core.test.js` 정적 검사에서 주석 내 예시 문구(`#ffffff`)가 순백 컬러 코드로 오인되지 않도록 주석을 먼저 strip한 후 검사하도록 정밀화함.
