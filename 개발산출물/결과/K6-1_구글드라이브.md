## 3. KZ-1이 쓸 값

### 3.1 `window.ULDrive` 공개 메서드 목록

- `requestToken(opts)`: Google Identity Services (`drive.file`, `window.ULEVELP_CONFIG.googleClientId`) 인메모리 액세스 토큰 획득 (`Promise<string>`).
- `ensureFolder(preferredId)`: `ULeveLP 녹음` 폴더 존재 확인 및 자동 생성 후 folderId 반환 (`Promise<string>`).
- `uploadBlob(blob, name, mime, folderId)`: 5MB 이하 multipart 단일 요청 / 5MB 초과 Resumable Upload 세션 분기 업로드 후 driveFileId 반환 (`Promise<string>`).
- `uploadTake(meta, blob)`: folder 확보 -> blob 업로드 -> `ULData.takes.registerDrive` 호출 (실패 시 Drive 고아 파일 `DELETE` 정리, `Promise<TakeDto>`).
- `fetchMediaObjectUrl(fileId)`: Google Drive `alt=media` 다운로드 후 `URL.createObjectURL` Blob URL 반환 (`Promise<string>`).
- `enableDriveStorage()`: 노션 연동 충돌 검증 -> Drive 저장소 활성화 및 `PATCH /api/v1/me` 호출 (`Promise<MeResponseDto>`).
- `disableDriveStorage()`: 기본 저장소로 복귀 및 `PATCH /api/v1/me` 호출 (`Promise<MeResponseDto>`).
- `migrateAllToDrive(onProgress)`: 노션 연동 충돌 검증 -> 기본 저장소(storage === 'supabase') 녹음 다운로드 -> Drive 업로드 -> `migrateToDrive` 일괄 이전 (실패 시 고아 파일 정리, `Promise<{ migrated, skipped }>`).
- `clearToken()`: 인메모리 OAuth 토큰 및 만료 시각 즉시 초기화 (로그아웃 및 `uid` 변경 시 호출).

## 4. 명세와 달라진 점 및 겪은 문제

- **명세와 달라진 점:**
  - Google Identity Services (`gsi/client`) 스크립트가 로드되면서 기본 `<style>` 태그를 동적으로 주입함에 따라 발생하는 `style-src-elem:inline` CSP 위반을 방지하기 위해, CSP `style-src`에 해당 인라인 스타일의 sha256 해시(`'sha256-RU4sU0AaS8IBGZx8XrGt/pa9A5SLA3dQszGeqT5L3Kw='`)를 명시적으로 허용함. `unsafe-inline`을 사용하지 않고 특정 해시만 허용하여 보안 원칙을 완벽히 준수함.
- **겪은 문제 및 해결:**
  - **GIS 스크립트 누락 및 클라이언트 ID 경로:** `practice.html`, `log.html`, `settings.html`에 `<script src="https://accounts.google.com/gsi/client" async defer></script>` 태그를 추가하고, `drive.js`에서 `window.ULEVELP_CONFIG.googleClientId`를 읽도록 수정함 (리뷰 1·2번).
  - **노션 상호 배타 UI:** `MeResponseDto`에 없는 `notionSync` 대신 `settings.js`의 `loadSyncStatus()`(`/api/v1/sync/notion`) 결과로 `#driveConflictNotice` 표시와 버튼 비활성화를 처리하고, 상태 표시(`#driveProviderText`)와 결과 메시지(`#driveStatusMsg`)를 분리하여 버튼 클릭 후 `fetchMe()` 시 메시지가 사라지지 않게 개선함 (리뷰 3번).
  - **계정 전환 토큰 폐기:** `drive.js`에서 `activeUid`를 추적하여 로그아웃뿐 아니라 A→B 전환 시에도 인메모리 토큰을 즉시 폐기하도록 개선하고, `test/data.test.js`에 `D35` 케이스를 추가함 (리뷰 4번).
  - **범위 밖 커밋 분리:** `f1e8c82`는 별도 브랜치 `fix/note`로 분리하여 PR #30을 생성하고, 본 PR에서는 해당 4개 파일을 `origin/main` 상태로 되돌림 (리뷰 5번).
  - **권장사항 반영:** `data.js`의 `downloadTakeBlob`에서 `getAccessToken()`과 `apiBaseUrl`을 적용하고, `drive.js`의 이전 대상을 `storage === 'supabase'`로 명확히 제한하며, 서버 API 실패 시 Drive 업로드 파일을 `DELETE`로 정리하는 로직을 추가함.
