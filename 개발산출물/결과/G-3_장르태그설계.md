# G-3 결과: 곡 장르 태그 저장 설계 (A안 — DB 컬럼 + API 필드)

- **날짜:** 2026-11-04 · **승인:** 사용자 2026-11-04 ("진행")
- **진행 파일:** `개발산출물/진행_홈메뉴장르.md`
- **구현은 G-3b** (이 파일만 읽고 시작할 수 있게 적음). 브랜치는 PR #60 머지 후 main에서 `feat/song-genre`

## 1. 장르 id (기준: `frontend/src/lib/genres.ts`의 `GENRES`)

`pop` `jazz` `rnb` `rock` `jpop` `ani` `etc` — 7개. 미지정은 NULL. 서버 쪽 허용 목록도 이 순서 그대로 쓴다.

## 2. DB — `src/main/resources/db/migration/V2__songs_genre.sql` (새 파일)

```sql
-- songs.genre: 홈 장르 바로가기·플레이어 장르 폴더용 (frontend/src/lib/genres.ts GENRES와 같은 id)
ALTER TABLE songs
  ADD COLUMN genre TEXT
  CHECK (genre IS NULL OR genre IN ('pop', 'jazz', 'rnb', 'rock', 'jpop', 'ani', 'etc'));
```

- 기본값 없음(NULL). 인덱스 없음(장르별 묶기는 프론트에서)
- `Tables.kt` `SongsTable`: `val genre = text("genre").nullable()` (`memo` 다음 줄)

## 3. API

### 응답 `SongDto` — 14개에서 15개 필드로
- `SongService.kt`: `SongDto`에서 `memo` 다음에 `val genre: String?` 추가, `rowToDto`에서 `genre = row[SongsTable.genre]`
- 모든 곡 응답(목록·by-video·상세·POST·PATCH)에 들어간다. `explicitNulls = true`라서 미지정이면 `"genre": null`

### `PATCH /api/v1/songs/{songId}`
- 본문에 `genre`를 추가한다. 판정은 **키가 있는지**로 한다(`body.containsKey("genre")`). 다른 필드와 달리 `null`도 의미가 있다(해제)
  - `"jazz"` 같은 7개 id 중 하나 → 설정
  - `null` → 해제(NULL)
  - 그 밖의 값(빈 문자열, 모르는 id, 숫자 등) → `400 INVALID_INPUT`, 메시지 `genre는 pop, jazz, rnb, rock, jpop, ani, etc 중 하나 또는 null이어야 합니다.`
- "수정할 값 없음" 판정에 genre도 넣는다. 문구: `수정할 값(status, memo, title, genre)이 없습니다.`
- `UpdateSongInput`(시그니처 변경 승인됨): `genre: String?`, `genreSet: Boolean = false` 추가. `genreSet`이 true일 때만 `it[genre] = input.genre`
- **outbox:** status·memo·title 중 하나라도 들어오면 지금처럼 `song upsert`를 적재한다. **장르만 바꾼 PATCH는 적재하지 않는다**(노션으로 보낼 속성이 바뀌지 않으므로)
- 바꾸지 않는 것: `POST /songs`(장르 안 받음), `POST /songs/migrate-local`, `GET /songs`(`?genre=` 필터 없음)

## 4. 노션·내보내기 — 바꾸지 않음
- push(`NotionPushWorker`): 장르를 보내지 않는다. 사용자 노션 DB에 장르 속성이 없고, `NotionPushApiTest`가 속성 11개를 단언한다
- pull(`NotionSyncService`): update 문이 genre를 건드리지 않으므로 기존 값이 유지된다(수정 불필요). 노션에서 새로 들어온 곡은 NULL
- 내보내기 CSV(`ExportImportService`): 이번 범위에서 제외

## 5. 프론트 — `frontend/src/lib/apiClient.ts`
- `SongDto`에 `genre: string | null;` (`memo` 다음)
- `updateSong(songId, patch: { status?; memo?; title?; genre?: string | null })`: `patch.genre !== undefined`이면 `body.genre = patch.genre`(null 포함 전송)
- 비로그인 곡(`ulp:v:*`)은 장르가 없다 → G-4에서 "미지정" 폴더에 넣는다
