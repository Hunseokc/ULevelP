`scripts/keyboard.py`와 `scripts/guitar.py`를 1:1로 이식한다. 모든 좌표 상수가 짝수이므로 정수 연산(`Int`)으로 출력한다(예: `x="70"`, `y="15"`). XML 이스케이프 헬퍼 `escapeXml(s: String): String`은 `&` → `&amp;`, `<` → `&lt;`, `>` → `&gt;`, `"` → `&quot;`, `'` → `&#x27;`로 변환한다.

### 2.4 `note/GeminiClient.kt` & `note/AnalyzeJobDispatcher.kt` (package `ulevelp.note`)

```kotlin
class GeminiApiException(
    val statusCode: Int,
    val code: String,
    override val message: String

data class GeminiGenerateResult(
    val analysis: JsonObject,
    val usageSummary: String

interface GeminiClient {
    suspend fun generateNoteAnalysis(
        apiKey: String,
        model: String,
        youtubeUrl: String,
        prompt: String,
        responseJsonSchema: JsonObject
    ): GeminiGenerateResult
}

class HttpGeminiClient(
    private val baseUrl: String = "https://generativelanguage.googleapis.com/v1beta",
    private val frameFps: Double = System.getenv("GEMINI_FRAME_FPS")?.toDoubleOrNull() ?: 0.2,
    private val maxAttempts: Int = 4,
    private val retryDelayBaseMs: Long = 30_000L,
    private val requestTimeout: Duration = Duration.ofMinutes(12),
    private val httpClient: HttpClient = HttpClient.newBuilder().connectTimeout(Duration.ofSeconds(15)).build()

```
- **HTTP 요청 형식 (`POST $baseUrl/models/$model:generateContent`):**
  - 헤더: `x-goog-api-key: $apiKey`, `Content-Type: application/json; charset=utf-8`, `Accept: application/json`
  - 타임아웃: 단일 요청당 **12분(`Duration.ofMinutes(12)`)** — 4회 시도(최대 48분) + 재시도 대기(30s + 60s + 90s = 3분) 합계가 최대 51분이 되어 Cloud Run Job의 60분(`--task-timeout=3600s`) 및 `executeJob`의 54분 애플리케이션 타임아웃 안에 반드시 끝나도록 보장한다.
  - 본문 JSON:
    ```json
    {
      "contents": [
        {
          "parts": [
            {
              "file_data": { "file_uri": "https://www.youtube.com/watch?v=..." },
              "video_metadata": { "fps": 0.2 }
            },
            { "text": "<prompt>" }
          ]
        }
      ],
      "generationConfig": {
        "responseMimeType": "application/json",
        "responseJsonSchema": { ... },
        "mediaResolution": "MEDIA_RESOLUTION_LOW",
        "thinkingConfig": { "thinkingLevel": "LOW" }
      }
    }
    ```
  - **재시도 및 키 무효 구분 규칙 (`scripts/analyze.py` 58~68줄 + `FR-KEY-5`):**
    - 응답 상태 코드가 `429`, `500`, `503` 중 하나이고 `attempt < maxAttempts`(4회)이면 `delay(retryDelayBaseMs * attempt)` 후 재시도한다.
    - `401`, `403`이거나, `400`이면서 응답 본문(`res.body()`)에 `"API_KEY_INVALID"`가 포함된 경우에만 키 오류로 판정하여 재시도하지 않고 즉시 `GeminiApiException(status, "PROVIDER_KEY_INVALID", "PROVIDER_KEY_INVALID: Gemini API 키가 유효하지 않거나 요청이 거부되었습니다 (HTTP $status).")`를 던진다. (메시지 앞에 `"PROVIDER_KEY_INVALID: "` 접두어를 고정하여 `analysis_jobs.error`에 저장되게 함으로써, 프런트엔드가 폴링 시 키 무효를 감지하고 `ulp:keys`의 `gemini` 캐시를 무효화할 수 있게 한다.)
    - `"API_KEY_INVALID"`가 없는 일반 `400`(비공개 영상, 길이 초과 영상, 잘못된 요청 파라미터)은 재시도하지 않고 즉시 `GeminiApiException(400, "GEMINI_API_ERROR", "Gemini 분석 호출에 실패했습니다 (HTTP 400).")`를 던진다(키 캐시 유지).
    - 그 외 오류 또는 4회 모두 실패 시 `GeminiApiException(status, "GEMINI_API_ERROR", "Gemini 분석 호출에 실패했습니다 (HTTP $status).")`를 던진다.
  - **응답 파싱:**
    - `candidates[0].content.parts` 배열에서 `thought != true`인 마지막 텍스트 파트의 `text` 문자열을 `Json.parseToJsonElement(text).jsonObject`로 파싱한다.

```kotlin
fun interface AnalyzeJobDispatcher {
    suspend fun dispatch(jobId: UUID)
}

/**
 * 운영 환경(CLOUD_RUN_ANALYZE_JOB_URI 설정 시):
 * GCP 메타데이터 서버(http://metadata.google.internal/computeMetadata/v1/instance/service-accounts/default/token)
 * 또는 고정 토큰에서 Bearer 토큰을 얻어 POST $jobUri 로
 * {"overrides":{"containerOverrides":[{"env":[{"name":"ANALYZE_JOB_ID","value":jobId.toString()}]}]}} 를 전송한다.
 */
class CloudRunJobDispatcher(
    private val jobUri: String,
    private val staticAccessToken: String? = System.getenv("CLOUD_RUN_ACCESS_TOKEN")?.takeIf { it.isNotBlank() },
    private val httpClient: HttpClient = HttpClient.newBuilder().connectTimeout(Duration.ofSeconds(10)).build()
) : AnalyzeJobDispatcher
```
- **작업 ID는 `args`가 아니라 `env`(`ANALYZE_JOB_ID`)로 넘긴다 (PR #27 리뷰 1번으로 수정):** Cloud Run의 `containerOverrides[].args`는 이미지 CMD를 통째로 바꾼다. `Dockerfile`은 `ENTRYPOINT` 없이 `CMD ["java", ..., "ulevelp.MainKt"]`만 두므로, `args`로 넘기면 컨테이너가 `--analyze-job`을 실행 파일로 띄우려다 실패한다. `env` 덮어쓰기는 CMD를 그대로 두고 `Main.kt`의 `ANALYZE_JOB_ID` 분기(5.3절)로 들어간다. `--analyze-job <jobId>` 인자는 로컬 수동 실행용으로 유지한다.

```kotlin
/**
 * 로컬 서버 실행 시(CLOUD_RUN_ANALYZE_JOB_URI 미설정 시) 백그라운드 코루틴으로 executeJob을 실행하는 기본 디스패처.
 */
class LocalAsyncJobDispatcher(
    private val runner: suspend (UUID) -> Unit,
    private val scope: CoroutineScope = CoroutineScope(SupervisorJob() + Dispatchers.IO)
) : AnalyzeJobDispatcher {
    override suspend fun dispatch(jobId: UUID) {
        scope.launch { runner(jobId) }
    }
}
```

## 5. 처리 순서·트랜잭션 경계

### 5.1 `requestAnalyze(userId, rawUrl, rawTags, memo, dispatcher)`
1. 입력 검증:
   - `videoId = ExportImportService.extractVideoId(rawUrl) ?: throw InvalidInputException("올바른 유튜브 영상 주소가 아닙니다.")`
   - `normalizedUrl = "https://www.youtube.com/watch?v=$videoId"`
   - `rawTags`의 각 원소를 trim하고 비어 있거나 `it !in GeminiSchemas.TAGS`인 원소가 있으면 `throw InvalidInputException("유효한 분석 태그를 1개 이상 선택해 주세요.")`.
   - `orderedTags = GeminiSchemas.TAGS.filter { it in rawTags.toSet() }` (`orderedTags.isEmpty()`이면 `400 INVALID_INPUT`).
2. `integrationService.requireDecryptedGemini(userId, "ulevelp")`를 호출해 사용자의 Gemini 키 등록 및 복호화 가능 여부를 확인한다(없으면 `412 NO_KEY`).
3. **트랜잭션 1 (동시성 잠금 + 제한 검사 + `analysis_jobs` `queued` 생성):**
   - `ProfilesTable.select(ProfilesTable.id).where { ProfilesTable.id eq userId }.forUpdate(ForUpdateOption.ForUpdate).single()`로 사용자 행을 잠근다.
   - `AnalysisJobsTable`에서 `(userId eq userId) and (status inList listOf("queued", "running"))` 건수가 `>= 1`이면 `429 RATE_LIMITED` (`retryAfter = 30`).
   - `todayStartUtc = LocalDate.now(clock.withZone(ZoneOffset.UTC)).atStartOfDay().atOffset(ZoneOffset.UTC)` 이후 생성된 해당 사용자의 `AnalysisJobsTable` 건수가 `>= 20`이면 내일 자정까지 남은 초(`Duration.between(clock.instant(), todayStartUtc.plusDays(1).toInstant()).seconds.toInt().coerceIn(1, 86400)`)와 함께 `429 RATE_LIMITED`.
   - `jobId = UUID.randomUUID()`로 `AnalysisJobsTable`에 `status = "queued"`, `url = normalizedUrl`, `tags = orderedTags`, `memo = memo`, `createdAt = nowUtc` INSERT.
4. **트랜잭션 밖 (`dispatcher.dispatch(jobId)` 호출):**
   - `try { dispatcher.dispatch(jobId) } catch (e: CancellationException) { throw e } catch (e: Exception)`:
     - 디스패치 실패 시 짧은 트랜잭션으로 방금 만든 `jobId` 행을 `status = "failed"`, `error = "dispatch_failed: ${(e.message ?: "").take(200)}"`, `finishedAt = nowUtc`로 갱신한 뒤 `ApiException(HttpStatusCode.BadGateway, "JOB_DISPATCH_ERROR", "분석 작업 실행 요청에 실패했습니다. 잠시 후 다시 시도해 주세요.")`를 던진다(작업이 영원히 `queued`에 멈추지 않도록 보호).
5. `AnalyzeJobCreateResponse(jobId = jobId.toString(), status = "queued")` 반환.

### 5.2 `executeJob(jobId)` (Cloud Run Job `analyze` 및 로컬 워커 실행 본체 — 54분 타임아웃 보장)
1. **트랜잭션 1 (`running` 상태 전환 및 입력 읽기):**
   - `AnalysisJobsTable`에서 `(id eq jobId) and (status eq "queued")`인 행을 조회해 `status = "running"`, `startedAt = nowUtc`로 UPDATE. 갱신된 행이 없으면(이미 실행 중이거나 완료됨) 즉시 종료.
   - `userId`, `url`, `tags`, `memo`를 읽는다.
2. **트랜잭션 밖 (외부 호출 — `withTimeout(jobTimeoutMs)` [기본 54분] 적용, DB 커넥션을 점유하지 않는다!):**
   - `try { withTimeout(jobTimeoutMs) { ... } }` 블록 안에서:
     1) `val gemini = integrationService.requireDecryptedGemini(userId, "ulevelp")`
     2) `val videoId = ExportImportService.extractVideoId(url) ?: throw InvalidInputException("잘못된 영상 URL")`
     3) `val meta = runCatching { videoMetaClient.fetch(videoId) }.getOrNull()`
        `val title = meta?.title?.takeIf { it.isNotBlank() }?.take(300) ?: url`
        `val channel = meta?.author?.take(200) ?: ""`
     4) `val (schema, prompt) = GeminiSchemas.buildPrompt(tags, memo)`
     5) `val result = geminiClient.generateNoteAnalysis(gemini.apiKey, gemini.model, url, prompt, schema)`
     6) `analysis = result.analysis`:
        - `headline = analysis["summary"]?.jsonObject?.get("headline")?.jsonPrimitive?.contentOrNull?.take(500) ?: ""`
        - `points = analysis["summary"]?.jsonObject?.get("points")?.jsonArray?.mapNotNull { it.jsonObject["point"]?.jsonPrimitive?.contentOrNull } ?: emptyList()`
        - `keywords = analysis["key_concepts"]?.jsonArray?.mapNotNull { it.jsonPrimitive.contentOrNull?.replace(",", " ")?.trim()?.take(100)?.takeIf(String::isNotEmpty) }?.distinct() ?: emptyList()`
        - `difficulty = analysis["difficulty"]?.jsonPrimitive?.contentOrNull?.takeIf { it in setOf("입문", "중급", "고급") }`
        - `diagramsSvg`: `analysis["harmony"]?.jsonObject?.get("progressions")?.jsonArray`가 있으면 각 progression을 `HarmonyProgressionDto`로 역직렬화하여 `instrument == "기타"`이면 `GuitarSvgRenderer.progressionSvg(p.chords) ?: ""`, 아니면 `KeyboardSvgRenderer.progressionSvg(p.chords) ?: ""`를 계산해 `List<String>`으로 만든다(화성 섹션이 없으면 `emptyList()`).
3. **트랜잭션 2 (성공 시 `notes` INSERT + `analysis_jobs` `done` 갱신 + Outbox 적재):**
   - `noteId = UUID.randomUUID()`로 `NotesTable`에 INSERT.
   - `AnalysisJobsTable.update({ id eq jobId }) { it[status] = "done"; it[AnalysisJobsTable.noteId] = noteId; it[error] = null; it[finishedAt] = nowUtc }`.
   - `OutboxRepository.enqueueIfSyncEnabled(userId, "note", noteId, "upsert")`.
4. **실패 및 타임아웃/취소 시 (`catch (e: Throwable)` — `withContext(NonCancellable)` 안에서 `failed` 기록 보장):**
   - `TimeoutCancellationException`은 `"분석 제한 시간(54분)을 초과하여 중단되었습니다."`로, 그 외 `CancellationException`은 `"분석 작업이 취소되었습니다."`로, 일반 `Exception`은 `(e.message ?: "분석 실패").take(500)`(키 무효 시 `"PROVIDER_KEY_INVALID: ..."` 원문 유지)로 `errMsg`를 만든다.
   - `withContext(NonCancellable)` 안에서 짧은 트랜잭션으로 `AnalysisJobsTable.update({ (id eq jobId) and (status neq "done") }) { it[status] = "failed"; it[error] = errMsg; it[finishedAt] = nowUtc }`를 실행해 어떤 경우에도 작업이 `running`에 남지 않게 보장한다.
   - 만약 `e is CancellationException && e !is TimeoutCancellationException`이면 DB 기록 후 `throw e`로 취소 신호를 다시 던진다.

### 5.3 `Main.kt`의 `--analyze-job` CLI 실행 분기 (`KC-D6`)
`Main.kt`의 `fun main(args: Array<String>)`에서:
- `val jobIdArg = args.indexOf("--analyze-job").takeIf { it >= 0 && it + 1 < args.size }?.let { args[it + 1] } ?: System.getenv("ANALYZE_JOB_ID")?.takeIf { it.isNotBlank() }`

### 5.4 `listJobs(userId)` 및 `getJob(userId, jobId)`
- `listJobs(userId)`: 단일 트랜잭션에서 `AnalysisJobsTable.selectAll().where { AnalysisJobsTable.userId eq userId }.orderBy(AnalysisJobsTable.createdAt to SortOrder.DESC, AnalysisJobsTable.id to SortOrder.DESC).limit(RECENT_JOBS_LIMIT)`를 조회하여 `AnalysisJobDto` 리스트로 변환해 반환한다.
- `getJob(userId, jobId)`: 단일 트랜잭션에서 `AnalysisJobsTable.selectAll().where { (AnalysisJobsTable.id eq jobId) and (AnalysisJobsTable.userId eq userId) }.singleOrNull()`을 조회한다. 없으면 `throw NotFoundException("분석 작업을 찾을 수 없습니다.")`.

### 5.5 `listNotes(userId, tag)` 및 `getNote(userId, noteId)`
- `listNotes(userId, tag)`:
  - `val trimmedTag = tag?.trim()?.takeIf { it.isNotEmpty() }`
  - `if (trimmedTag != null && trimmedTag !in GeminiSchemas.ALLOWED_NOTE_TAGS) throw InvalidInputException("유효하지 않은 태그 필터입니다.")`
  - 단일 트랜잭션에서 `NotesTable.selectAll().where { NotesTable.userId eq userId }.orderBy(NotesTable.createdAt to SortOrder.DESC, NotesTable.id to SortOrder.DESC)`를 조회한 뒤, `trimmedTag != null`이면 `trimmedTag in row[NotesTable.tags]`로 필터링하여 `NoteSummaryDto` 리스트를 반환한다.
- `getNote(userId, noteId)`:
  - 단일 트랜잭션에서 `NotesTable.selectAll().where { (NotesTable.id eq noteId) and (NotesTable.userId eq userId) }.singleOrNull()`을 조회한다. 없으면 `throw NotFoundException("학습 노트를 찾을 수 없습니다.")`.
  - `rowToNoteDetailDto(row)`로 변환해 반환한다.

### 5.6 `updateNote(userId, noteId, newMemo, newTags, newTitle)` 및 `deleteNote(userId, noteId)`
- **`NoteRoutes.kt`의 `PATCH /api/v1/notes/{noteId}` 본문 파싱 및 검증 순서:**
  1. `val noteId = parsePathUuid(call.parameters["noteId"])`
  2. `val body = call.receiveJsonObject()`
  3. `val hasTitle = body.containsKey("title")`, `val hasMemo = body.containsKey("memo")`, `val hasTags = body.containsKey("tags")`
  4. 셋 다 `false`이면 `throw InvalidInputException("수정할 항목(title, memo, tags 중 하나 이상)이 필요합니다.")`
  5. `hasTitle == true`일 때: `body["title"]`이 `JsonPrimitive` 문자열이 아니거나 `trim()` 결과가 빈 문자열이면 `throw InvalidInputException("title은 빈 문자열일 수 없습니다.")`, 300자를 초과하면 `throw InvalidInputException("title은(는) 300자 이하여야 합니다.")`.
  6. `hasMemo == true`일 때: `body["memo"]`가 `JsonPrimitive` 문자열이 아니면 `throw InvalidInputException("memo 형식이 올바르지 않습니다.")`, `trim()` 결과가 2,000자를 초과하면 `throw InvalidInputException("memo은(는) 2000자 이하여야 합니다.")`.
  7. `hasTags == true`일 때: `body["tags"]`가 `JsonArray`가 아니거나 `size !in 1..7`이면 `throw InvalidInputException("tags는 1개 이상 7개 이하여야 합니다.")`. 각 원소가 문자열이 아니거나 `trim()` 결과가 `GeminiSchemas.ALLOWED_NOTE_TAGS`에 없으면 `throw InvalidInputException("유효하지 않은 태그가 포함되어 있습니다.")`. 중복은 입력 순서를 보존해 `distinct()`로 제거한다.
- **`NoteService.updateNote` 트랜잭션:**
  1. `NotesTable`에서 `(id eq noteId) and (userId eq userId)` 존재 확인(없으면 `throw NotFoundException("학습 노트를 찾을 수 없습니다.")`).
  2. `nowUtc = clock.instant().atOffset(ZoneOffset.UTC)`로 전달된 필드(`title`, `memo`, `tags`)와 `updatedAt = nowUtc`를 `NotesTable.update`로 반영한다.
  3. 같은 트랜잭션에서 `OutboxRepository.enqueueIfSyncEnabled(userId, "note", noteId, "upsert")`를 호출한다.
  4. 갱신된 행을 읽어 `NoteDetailDto`를 반환한다.
- **`NoteService.deleteNote` 트랜잭션:**
  1. `NotesTable`에서 `(id eq noteId) and (userId eq userId)` 존재 확인(없으면 `throw NotFoundException("학습 노트를 찾을 수 없습니다.")`).
  2. 같은 트랜잭션에서 `OutboxRepository.enqueueIfSyncEnabled(userId, "note", noteId, "delete")`를 호출한 뒤 `NotesTable.deleteWhere { (id eq noteId) and (NotesTable.userId eq userId) }`를 실행한다.
