- `minutes`, `segment`, `TakeDto` 변환은 K2-1에서 만든 `SessionService.toMinutes`, `SessionService.formatSegment`, `SessionService.rowToTakeDto`를 그대로 호출한다.

### 2.2 `routes/SongRoutes.kt` 추가분

`route("/songs")` 블록 안(`get("/by-video/{videoId}")` 아래, `patch("/{songId}")` 위)에 추가한다:

```kotlin
get("/{songId}") {
    val user = call.requireAuthUser()
    val songId = parsePathUuid(call.parameters["songId"])
    val detail = songService.getDetail(user.id, songId)
    call.response.headers.append(HttpHeaders.CacheControl, "no-store")
    call.respond(HttpStatusCode.OK, detail)
}
```

### 2.3 `public/data.js` 추가 시그니처

`songs` 객체에 아래 3개 비동기(`async`) 함수를 추가한다:

| 이름 | 인자 | 요청 | 반환(Promise) |
| --- | --- | --- | --- |
| `songs.get(songId)` | `songId`(문자열) | `GET /api/v1/songs/` + `encodeURIComponent(songId)` | 서버 응답 객체 `{ song, sessions, takes }` |
| `songs.update(songId, patch)` | `songId`(문자열), `patch = { status, memo, title }` | `PATCH /api/v1/songs/` + `encodeURIComponent(songId)`, 본문은 `patch`에서 `undefined`가 아닌 `status`·`memo`·`title` 키만 추린 JSON | `r.song` |
| `songs.remove(songId)` | `songId`(문자열) | `DELETE /api/v1/songs/` + `encodeURIComponent(songId)` | `{ ok: true }` |

- 3개 모두 첫 줄에서 `requireLogin()`을 호출해 비로그인 시 Promise reject(`NOT_LOGGED_IN`, 401)를 반환한다.

### 2.4 `public/log.html` & `public/log.js` 확장 (곡 탭·곡 상세·A/B 비교)

#### 1) 라우팅 및 탭 전환 규칙
- URL 쿼리에 `?song={songId}`가 있으면 **곡 상세 모드(`#pane-song-detail`)**를 연다 (`#logTabs`, `#pane-log`, `#pane-songs`는 숨김).
- `?song=`이 없으면 탭 모드(`#pane-log` 또는 `#pane-songs`)를 보여주며, `location.hash === '#songs'`이거나 `#tab-songs`를 누르면 곡 탭(`#pane-songs`)을 활성화한다.
- 곡 상세에서 `← 목록으로` 버튼을 누르면 `history.pushState(null, '', 'log.html#songs')` 후 곡 탭(`#pane-songs`)으로 돌아간다.

  - 필터 클릭 시 `ULData.songs.list(status)` 호출(또는 전체 목록 캐시 필터링) 후 `#songList` 렌더링.
- 곡 목록(`#songList`):
  - 0건이면 `<p class="empty">등록된 연습 곡이 없어요.</p>`.
  - 각 곡 카드(`.card.song-card`):
    - 제목 링크: `<a class="song-detail-link" href="log.html?song={encodeURIComponent(s.id)}"><b>{s.title}</b></a>` (`s.artist`가 있으면 옆에 `<span class="meta">{s.artist}</span>`).
    - 우측 바로가기: `<a class="ghost mini" href="{safeUrl(s.resumeUrl) || ('practice.html?v=' + encodeURIComponent(s.videoId))}">▶ 이어서 연습</a>`.
    - 요약 줄(`.meta`): `"누적 " + fmtDuration(s.totalSeconds) + (s.lastDate ? " · 최근 연습 " + s.lastDate : " · 연습 기록 없음")`.
    - 편집 줄(`.row`):
      - 상태 `<select aria-label="곡 상태">`: 옵션 `연습 중`(`practicing`), `보류`(`paused`), `완료`(`done`). 변경(`change`) 시 즉시 `ULData.songs.update(s.id, { status: select.value })` 호출.
      - 메모 `<input class="inp" type="text" maxlength="2000" placeholder="곡 메모">` (`input.value = s.memo`) + `<button type="button" class="ghost mini">메모 저장</button>`.
      - 삭제 `<button type="button" class="ghost mini">곡 삭제</button>`: 클릭 시 `window.confirm('이 곡과 모든 연습 기록·녹음 파일을 함께 삭제할까요?')` (`FR-SONG-5`) → 승인 시 `ULData.songs.remove(s.id)` 호출 후 목록에서 제거.

  - `sessions`가 비어 있으면 `<p class="empty">아직 연습 세션 기록이 없어요.</p>`.
  - `maxSec = Math.max(60, ...sessions.map(s => s.seconds))` 계산.

    - 날짜·구간·배속(`s.date`, `s.segment`, `s.rate`), 연습 시간(`s.minutes + '분'`, `s.loops + '회'`).
    - 막대 시각화: CSP 규칙(`test/security.test.js` (a) 규칙: `style=` 속성 금지)을 준수하기 위해 `<progress class="tl-bar" max="{maxSec}" value="{s.seconds}"></progress>` 요소를 사용한다 (`style="width:..."` 인라인 스타일 절대 금지!).
    - 세션 메모가 있으면 아래에 표시.
- **전체 녹음 테이크 목록 (`#detailTakes`) 및 A/B 비교 듣기 (`FR-LIB-3`):**
  - `takes`가 비어 있으면 `<p class="empty">아직 녹음된 테이크가 없어요.</p>`.
  - 각 녹음(`t`)마다 행(`.take-row`):
    - 체크박스: `<label class="check"><input type="checkbox" class="ab-check" data-take-id="{t.id}"><span>비교 선택</span></label>`.
    - 설명: 녹음 일시(`t.recordedAt.slice(0, 16).replace('T', ' ')`), 구간(`t.a != null && t.b != null`), 속도(`t.rate`), 길이(`t.durationSec + '초'`).
    - 개별 `▶ 듣기` 버튼, `삭제` 버튼, `<audio controls preload="none" hidden></audio>`.
  - **A/B 비교 재생 패널 (`#abPanel`, `FR-LIB-3`):**
    - 체크박스로 선택된 녹음 ID 배열 `abSelected`(최대 2개 유지 — 이미 2개가 선택된 상태에서 3번째를 체크하면 가장 먼저 선택한 것을 해제하거나 체크를 막고 2개만 유지).
    - `abSelected.length === 2`일 때만 `#abPanel.hidden = false`, 아니면 `#abPanel.hidden = true` (패널이 닫힐 때 두 오디오 정지).
    - 선택된 두 녹음을 `recordedAt` 오름차순으로 정렬해 먼저 녹음한 것을 **A (과거 녹음)**, 나중에 녹음한 것을 **B (최근 녹음)** 슬롯에 배치한다.
    - 패널 안에는 슬롯 A(`#abSlotA`: 라벨 `#abLabelA`, 재생/일시정지 버튼 `#abPlayA`, `<audio id="abAudioA" controls preload="none"></audio>`)와 슬롯 B(`#abSlotB`: 라벨 `#abLabelB`, 재생/일시정지 버튼 `#abPlayB`, `<audio id="abAudioB" controls preload="none"></audio>`)를 둔다.
    - **상호 배타 재생 규칙 (`FR-LIB-3` 필수):**
      - `#abAudioA`의 `play` 이벤트(또는 `#abPlayA` 클릭) 시 `#abAudioB.pause()`를 즉시 호출한다.
      - `#abAudioB`의 `play` 이벤트(또는 `#abPlayB` 클릭) 시 `#abAudioA.pause()`를 즉시 호출한다.
      - 각 슬롯의 서명 URL은 선택 시점(또는 재생 클릭 시점)에 `ULData.takes.getUrl(takeId)`로 받아 `safeUrl(r.url)`을 `.src`에 설정한다.

## 3. DTO 필드 표 (`GET /api/v1/songs/{songId}`)

**최상위 응답 (`SongDetailResponse`, `200 OK`):**
| 필드 | 타입 | null | 설명 |

## 5. 처리 순서·트랜잭션 경계

### 5.1 `SongService.getDetail(userId, songId)` (트랜잭션 1개)
1. `SongsTable.selectAll().where { (SongsTable.id eq songId) and (SongsTable.userId eq userId) }.singleOrNull()` → 없으면 `throw NotFoundException("곡을 찾을 수 없습니다.")`.
2. `SessionsTable.selectAll().where { (SessionsTable.userId eq userId) and (SessionsTable.songId eq songId) }.orderBy(SessionsTable.date to SortOrder.DESC, SessionsTable.updatedAt to SortOrder.DESC).toList()` 조회.
3. `totalSec = sessionRows.sumOf { it[SessionsTable.seconds].toLong() }`.
4. `songDto = rowToDto(songRow, totalSec)`.
5. `sessions = sessionRows.map { row -> SongSessionDto(...) }`.
6. `takes = TakesTable.selectAll().where { (TakesTable.userId eq userId) and (TakesTable.songId eq songId) }.orderBy(TakesTable.recordedAt to SortOrder.DESC).map { SessionService.rowToTakeDto(it) }`.
7. `SongDetailResponse(song = songDto, sessions = sessions, takes = takes)` 반환.
