## 2. 시그니처

### 2.1 `service/SessionService.kt` (package `ulevelp.service`)

```kotlin
@Serializable
data class SessionSummaryDto(
    val thisWeekSeconds: Long,
    val thisMonthSeconds: Long
)

@Serializable
data class CalendarDayDto(
    val date: String,
    val totalSeconds: Long,
    val level: Int
)

@Serializable
data class SessionWithSongDto(
    val id: String,
    val songId: String,
    val songTitle: String,
    val songArtist: String,
    val videoId: String,
    val date: String,
    val seconds: Int,
    val minutes: Double,
    val loops: Int,
    val a: Double?,
    val b: Double?,
    val segment: String,
    val rate: Double?,
    val memo: String,
    val takes: List<TakeDto>
)

@Serializable
data class SessionListResponse(
    val summary: SessionSummaryDto,
    val calendar: List<CalendarDayDto>,
    val sessions: List<SessionWithSongDto>
)

class SessionService(private val db: Database?) {
    suspend fun list(userId: UUID, from: LocalDate, to: LocalDate, today: LocalDate): SessionListResponse
    suspend fun updateMemo(userId: UUID, sessionId: UUID, memo: String)

    companion object {
        const val DEFAULT_CALENDAR_DAYS = 84L   // 12주 = 84일 (today - 83일 ~ today)
        const val MAX_RANGE_DAYS = 365L         // ChronoUnit.DAYS.between(from, to) <= 365 (최대 366일)

        /**
         * 연습 시간(초) → 달력 농도 단계(1~4).
         * 1..899초(15분 미만) -> 1, 900..1799초(30분 미만) -> 2, 1800..3599초(60분 미만) -> 3, 3600초 이상 -> 4.
         * 0초 이하는 0.
         */
        fun levelForSeconds(totalSeconds: Long): Int

        /**
         * a, b가 둘 다 null이 아니면 "${formatMmSs(a)}–${formatMmSs(b)}" (en dash '\u2013'), 아니면 "".
         * formatMmSs(x): 초를 floor 정수 내림해 m:ss (초는 2자리 0 패딩). 예: 38.0 -> "0:38", 125.9 -> "2:05".
         */
        fun formatSegment(a: BigDecimal?, b: BigDecimal?): String

        /** seconds -> 소수 첫째 자리 반올림 분 (Math.round(seconds / 60.0 * 10) / 10.0) */
        fun toMinutes(seconds: Int): Double

        /** TakesTable ResultRow -> TakeDto 변환 (K2-2에서도 공용으로 씀) */
        fun rowToTakeDto(row: ResultRow): TakeDto
    }
}
```
- `requireDb()`는 `SongService.kt`처럼 private으로 둔다(`503 DB_UNAVAILABLE`). 모든 DB 접근은 `DatabaseFactory.dbQuery(database) { }`.

### 2.2 `routes/SessionRoutes.kt` (package `ulevelp.routes`)

`SongRoutes.kt`처럼 작성한다 (`install(SupabaseAuthPlugin)`, 응답마다 `Cache-Control: no-store`).

```kotlin
fun Route.registerSessionRoutes(
    jwtVerifier: SupabaseJwtVerifier?,
    profileService: ProfileService,
    sessionService: SessionService
)
//   route("/sessions") {
//     install(SupabaseAuthPlugin) { ... }
//     get { }                    GET   /api/v1/sessions
//     patch("/{sessionId}") { }  PATCH /api/v1/sessions/{sessionId}
//   }
```
- 쿼리 날짜 파싱(라우트 내부 private 헬퍼 `parseQueryDate(name: String, raw: String?): LocalDate?`):
  - `raw.isNullOrBlank()`이면 `null` 반환.
  - `^\d{4}-\d{2}-\d{2}$` 불일치 또는 `LocalDate.parse` 실패 → `InvalidInputException("$name 형식이 올바르지 않습니다.")`.
  - `2000-01-01` 미만 또는 `LocalDate.now(ZoneOffset.UTC).plusDays(1)` 초과 → `InvalidInputException("${name}은(는) 2000-01-01부터 내일(UTC)까지만 쓸 수 있습니다.")`.
- `GET /api/v1/sessions` 날짜 결정 순서:
  1. `val today = parseQueryDate("today", call.request.queryParameters["today"]) ?: LocalDate.now(ZoneOffset.UTC)`
  2. `val to = parseQueryDate("to", call.request.queryParameters["to"]) ?: today`
  3. `val from = parseQueryDate("from", call.request.queryParameters["from"]) ?: to.minusDays(SessionService.DEFAULT_CALENDAR_DAYS - 1)`
  4. `if (from > to)` → `InvalidInputException("from은 to보다 늦을 수 없습니다.")`
  5. `if (ChronoUnit.DAYS.between(from, to) > SessionService.MAX_RANGE_DAYS)` → `InvalidInputException("조회 기간은 최대 366일까지 가능합니다.")`
- `PATCH /api/v1/sessions/{sessionId}`:
  - `val sessionId = parsePathUuid(call.parameters["sessionId"])`
  - `val body = call.receiveJsonObject()`
  - `val memo = body.requireString("memo", 2000)`
  - `sessionService.updateMemo(user.id, sessionId, memo)`
  - `call.response.headers.append(HttpHeaders.CacheControl, "no-store")`
  - `call.respond(HttpStatusCode.OK, buildJsonObject { put("ok", true) })`

기존 `isLoggedIn`, `songs.{list, byVideo, create}`, `saveProgress`, `takes.upload`, `runLocalMigration`은 그대로 두고 아래 4개 함수를 추가해 내보낸다.

| 이름 | 인자 | 요청 | 반환(Promise) |
| --- | --- | --- | --- |
| `sessions.list(params)` | `params = { from, to, today }` 또는 생략 | `GET /api/v1/sessions` (+ 있는 키만 `URLSearchParams`로 쿼리 추가) | 서버 응답 객체 `{ summary, calendar, sessions }` |
| `sessions.updateMemo(sessionId, memo)` | `sessionId`(문자열), `memo`(문자열) | `PATCH /api/v1/sessions/` + `encodeURIComponent(sessionId)`, 본문 `JSON.stringify({ memo: String(memo ?? '') })` | `{ ok: true }` |
| `takes.getUrl(takeId)` | `takeId`(문자열) | `GET /api/v1/takes/` + `encodeURIComponent(takeId)` + `/url` | `{ url, expiresIn }` |

- 4개 모두 `async function`으로 선언하고 첫 줄에서 `requireLogin()`을 부른다(비로그인 시 동기 예외가 아니라 Promise reject `code = 'NOT_LOGGED_IN'`, `status = 401`이 되도록 — 주니어 체크리스트 "비동기 인터페이스는 항상 Promise reject 반환").

#### `public/log.js` 동작 (K2-1 범위)
1. **날짜 계산:**
   - 기기 현지 날짜 `todayStr()`: `YYYY-MM-DD`.
   - 12주(84일) 배열 `build84Days(todayStr)`: `today - 83일`부터 `today`까지 84개의 `YYYY-MM-DD` 배열 생성.
   - 시간 포맷 `fmtDuration(sec)`:
     - `sec <= 0` → `'0분'`
     - 60초 미만 → `sec + '초'`
     - 3600초 미만 → `Math.round(sec / 60) + '분'`
     - 3600초 이상 → `Math.floor(sec / 3600) + '시간'` + (나머지 분이 있으면 `' ' + Math.round((sec % 3600) / 60) + '분'`, 0분이면 생략).
2. **초기 로드 및 인증 연동 (`ULAuth.onChange`):**
   - `practice.js`처럼 시작 시 `if (window.ULAuth) await ULAuth.getAccessToken();` 후 `render()` / `loadLog()` 실행.
   - `ULAuth.onChange`에서 `uid`가 바뀌거나 로그아웃되면:
     - 이전 사용자의 상태(`sessionsData = null`, `selectedDate = null`, 열린 오디오 URL 캐시)를 **즉시 초기화**한다 (주니어 체크리스트 "로그아웃·계정 전환 시 이전 사용자 상태 초기화").
     - 비로그인이면 `#logGuest`를 보이게 하고 `#pane-log`, `#pane-songs`를 숨긴다.
     - 로그인이면 `#logGuest`를 숨기고 `loadLog()`를 호출한다 (`sameUid`이고 이미 불러왔으면 중복 호출하지 않음).
3. **`loadLog()`:**
   - `const t = todayStr();`
   - `ULData.sessions.list({ today: t })` 호출.
   - 응답 `{ summary, calendar, sessions }` 수신:
     - `#sumWeek.textContent = fmtDuration(summary.thisWeekSeconds)`
     - `#sumMonth.textContent = fmtDuration(summary.thisMonthSeconds)`
     - `calendar` 배열을 `date -> { totalSeconds, level }` 맵으로 변환.
     - 기본 선택 날짜 `selectedDate`: 아직 선택된 날짜가 없으면 `sessions`가 있는 가장 최근 `date`, 세션이 하나도 없으면 `t`(`today`).
     - 달력과 선택된 날짜의 세션 목록을 렌더링한다.
4. **12주 달력 렌더링 (`renderCalendar`):**
   - 84일 배열을 순회하며 각 날짜마다 `<button type="button" class="cal-day lv{0..4}" data-date="YYYY-MM-DD" aria-pressed="{선택여부}" aria-label="YYYY-MM-DD · {분}">` 생성 (DOM API `createElement` + `textContent`/`setAttribute` 사용 또는 `esc()` 적용).
   - 기록 없는 날은 `lv0`(테두리 선만), 기록 있는 날은 서버 `level`(`1`~`4`)에 따라 `lv1`~`lv4` 클래스를 붙인다.

## 5. 처리 순서·트랜잭션 경계

### 5.1 `SessionService.list(userId, from, to, today)` (트랜잭션 1개)
1. **주간·월간 범위 계산:**
   - `weekStart = today.with(TemporalAdjusters.previousOrSame(DayOfWeek.MONDAY))`
   - `weekEnd = weekStart.plusDays(6)`
   - `monthStart = today.withDayOfMonth(1)`
   - `monthEnd = today.with(TemporalAdjusters.lastDayOfMonth())`
2. **주간·월간 합계 조회:**
   - `sumExpr = SessionsTable.seconds.sum()`
   - `thisWeekSeconds`: `SessionsTable.select(sumExpr).where { (userId eq userId) and (date greaterEq weekStart) and (date lessEq weekEnd) }.singleOrNull()?.get(sumExpr)?.toLong() ?: 0L`
   - `thisMonthSeconds`: `SessionsTable.select(sumExpr).where { (userId eq userId) and (date greaterEq monthStart) and (date lessEq monthEnd) }.singleOrNull()?.get(sumExpr)?.toLong() ?: 0L`
3. **기간 내 세션 + 곡 조인 조회:**
   - `(SessionsTable innerJoin SongsTable)`에서 `(SessionsTable.userId eq userId) and (SessionsTable.date greaterEq from) and (SessionsTable.date lessEq to)` 조건으로 조회.
   - 정렬: `orderBy(SessionsTable.date to SortOrder.DESC, SessionsTable.updatedAt to SortOrder.DESC)`.
4. **기간 내 세션들의 녹음(`takes`) 일괄 조회:**
   - 조회된 `sessionIds`가 비어 있지 않으면 `TakesTable.selectAll().where { (TakesTable.userId eq userId) and (TakesTable.sessionId inList sessionIds) }.orderBy(TakesTable.recordedAt to SortOrder.ASC)`로 읽어 `sessionId`별 리스트 맵으로 묶는다.
5. **달력 집계 (`calendar`):**
   - 3번에서 읽은 세션 행들을 `date`별로 `seconds` 합산(`totalSeconds`).
   - `totalSeconds > 0L`인 날짜만 `date` 오름차순으로 정렬하여 `CalendarDayDto(date.toString(), totalSeconds, levelForSeconds(totalSeconds))` 생성 (0초 세션만 있는 날은 달력 배열에 넣지 않음).
6. **`SessionListResponse` 반환.**

### 5.2 `SessionService.updateMemo(userId, sessionId, memo)` (트랜잭션 1개)
1. `val updated = SessionsTable.update({ (SessionsTable.id eq sessionId) and (SessionsTable.userId eq userId) }) { it[SessionsTable.memo] = memo }`
2. `if (updated == 0) throw NotFoundException("연습 기록을 찾을 수 없습니다.")`
3. `OutboxRepository.enqueueIfSyncEnabled(userId, "session", sessionId, "upsert")`

## 9. 금지 사항

- 3절 표에 없는 DTO 필드를 추가하거나 빼지 않는다.
- `GET /api/v1/songs/{songId}`나 `log.html`의 곡 탭·곡 상세·A/B 비교 듣기를 이 step에서 미리 구현하지 않는다(K2-2 범위).
- `data.js`의 비동기 함수에서 비로그인 시 동기로 `throw`하지 않는다(반드시 `async` 함수 안에서 던지거나 `Promise.reject`를 반환).
- `log.js`에서 외부 텍스트(`songTitle`, `songArtist`, `memo`)를 `esc()` 없이 `innerHTML`에 넣거나 `style="..."` 인라인 속성을 쓰지 않는다.
- 로그아웃·계정 전환(`uid` 변경) 시 이전 사용자의 `sessionsData`나 오디오 요소를 화면에 남겨 두지 않는다.
- K2-2를 이어서 진행하지 않는다.
