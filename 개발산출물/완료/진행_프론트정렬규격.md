## 1. 검토 결론 (2026-11-04)

**일반화할 수 있다.** 단 자동 검사가 잡는 것은 "깨짐"이고 "부자연스러움"은 일부만 잡힌다. 그래서 규격은 세 층으로 한다: **자동 공통 검사 + 화면별 배치 약속 + 스크린샷 검토**.

### 1-1. 화면과 무관하게 일반화되는 규칙

이번 검사는 홈 전용 `id`로 대상을 골랐지만, 판정 방식은 화면과 무관한 기하 규칙이다.

| ID | 규칙 | 자동 판정 방법 | 화면별 설정 |
| --- | --- | --- | --- |
| G1 | 넘침: 자식이 카드 밖으로 나감 | 테두리나 배경이 있는 상자를 "카드"로 자동 인식, 보이는 자손의 rect가 카드 rect 안에 있는지 | 없음 |
| G2 | 형제 겹침 | 같은 부모의 보이는 형제 rect 교차 | 없음 |
| G3 | 의도치 않은 말줄임·글자 넘침 | `scrollWidth > clientWidth + 1` | 의도한 말줄임(곡 제목 등)만 예외 표시 |
| G4 | 가로 스크롤 | 기존 `layout.spec.js` 흡수 | 없음 |
| G5 | 금지 색·토큰 위반 | 계산된 color·background·border가 허용 팔레트(`tokens.css`) 안에 있는지, 화면별 금지 색(예: 홈의 `--link`) | 금지 색 목록(선택) |
| G6 | 처짐 | 카드 제목(첫 자식) 아래에서 다음 내용까지의 간격이 기준값 이하 | 기준값 하나(홈은 24px) |
| G7 | 터치 대상 | 버튼·링크 높이가 최소값 이상(`DESIGN.md` 필 버튼 높이 참고) | 없음 |
| G8 | 간격 스케일 | 같은 줄 형제 간격이 간격 스케일(4·8·12·16…) 안 | 없음 |

### 1-2. 자동으로 판단할 수 없는 것 → 다른 층이 맡는다

- **같은 줄 카드의 높이와 윗선을 맞춰야 하는지는 화면 의도에 달렸다.** 홈의 CHORDS·PLAYER 아랫선 맞춤도 "빈 상태에선 맞아야 한다"고 정했기 때문에 검사가 가능했다 → **화면별 배치 약속**(§3 ③)으로 선언
- **시각적 균형과 위계**(여백이 어색한지, 무게 중심이 쏠렸는지)는 측정할 수 없다 → **스크린샷 검토**(§3 ④): 4개 폭을 캡처해 모델이 질문 목록으로 검토하고 결과 파일에 기록
- **스크린샷 비교 테스트(`toHaveScreenshot`)는 "바뀜"만 잡고 "틀림"은 못 잡는다.** Windows 로컬과 Linux CI의 글꼴 렌더링 차이 때문에 기준 이미지는 CI에서 만들어야 한다 → **1차 범위에서 제외**(제안, §5 결정 2)

## 2. 이번 홈 작업에서 나온 "자주 깨지는 원인" (규격 문서에 그대로 옮긴다)

| 원인 | 증상 | 홈 실측 |
| --- | --- | --- |
| 카드에 `justify-content: space-between` | 내용이 카드 바닥으로 처짐 | 제목 아래 58~63px 빔 |
| 그리드 칸보다 넓은 고정폭 자식 | 옆 칸 글자와 겹침 | 104px 칸에 120px 박스 → 4px 겹침 |
| 칸을 늘리는 `flex: 1` | 나란한 목록의 아랫선 어긋남 | 4px |
| `align-items: center` | 썸네일·글 윗선 어긋남 | 2~24px |
| 한 줄 `nowrap` + 말줄임 | 설명이 "…출…"로 잘림 | 238 > 219px |
| 전역 `a { color: var(--link) }` 상속 | 의도치 않은 파란색 | 링크 13곳 |
| `justify-content: flex-end` 단독 링크 | 링크가 혼자 구석에 뜸 | 264~480px |

## 6. 위험

- 기존 7개 화면에 적용하면 실패가 많이 나올 수 있다(홈만 14개). 그래서 FT-2는 기록만 하고 수정은 FT-3로 나눈다
- 공통 규칙은 오탐이 생긴다(장식 요소, 의도한 겹침). `data-layout-ignore` 예외에는 반드시 사유를 적는다. 예외가 늘어나면 검사가 무의미해진다
- 마크업 속성 추가는 파일 3개 이상 변경이라 FT-0 끝에 파일 목록을 승인받는다
- E2E 시간은 8개 화면 × 4개 폭 × 2~3개 상태로 1~2분 늘어날 것으로 예상(실측 아님, FT-2에서 기록)
