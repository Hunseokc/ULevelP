문제: takes는 recorded_at·duration_sec·mime(CHECK 6종)·size_bytes가 NOT NULL인데(V1__init.sql:84-99), ZIP 가져오기·노션 이관 모두 이 값을 어디서 얻는지 없습니다. 내보내기 파일명은 {date}_{HHmmss}_…(초까지, UTC)라 recordedAt 복원 규칙이 필요하고, 길이는 ZIP·노션 어디에도 없습니다.
고칠 방향: 컬럼별 규칙을 표로 고정. 예) recordedAt = 파일명 YYYY-MM-DD_HHmmss(UTC) 파싱, 실패 시 {date}T00:00:00Z / durationSec = 0 / mime = 확장자→MIME 표(TakeService.MIME_EXT 역매핑), 표에 없는 확장자는 errors에 기록 후 건너뜀 / a·b·rate = 소속 세션 값 복사. 노션 파일명 형식("$date ${HHmm} $title.$ext", 서울 시각, 분 단위)도 같은 표에 적어 주세요.
